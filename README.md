# mf-updator

Money Forward MEをローカルのPlaywrightブラウザーから操作するためのツールです。

## Milestone 1: 手動ログイン

```bash
npm install
npx playwright install chromium
npm run login
```

ブラウザーが開いたらMoney Forward MEに手動でログインしてください。口座ページへの到達を確認すると、認証状態を `data/auth-state.json` に保存します。次回の `npm run login` では保存済み状態を読み込み、期限切れの場合はブラウザー上で再ログインできます。

認証状態はローカルにのみ保存され、Git管理対象外です。パスワードや二段階認証の自動入力は行いません。

## Milestone 2: 明細を1件表示

```bash
npm run inspect
```

保存済み認証状態で家計簿ページを開き、表示中の先頭1件を読み取り専用で表示します。明細がない場合や画面構造を確認できない場合は停止します。明細の変更は行いません。

振替候補を1件だけ確認する場合:

```bash
npm run inspect:transfer
```

大項目欄が空の明細を振替候補として扱います。候補がない場合は停止します。

## 5年間の振替解除

```bash
npm run dry-run -- --from=2026-05-01 --to=2026-05-31 --description="口座振替 PayPayカード" --account="SBI銀行マサシ/マサシ個人収支"
```

`--from` と `--to` は両端を含みます。`--from` を省略すると利用可能な最古月まで、`--to` を省略すると今日まで走査します。一致した振替明細を一覧表示します。表示内容を確認した後、同じ条件を `apply` に渡すと、一件ずつ解除します。

```bash
npm run apply -- --from=2026-05-01 --to=2026-05-31 --description="口座振替 PayPayカード" --account="SBI銀行マサシ/マサシ個人収支"
```

各明細の直前にID・内容・金額・振替状態を再確認します。確認UIが解除を示さない場合、解除後の画面状態を確認できない場合、または1件でも失敗した場合は残りを停止します。結果は明細の日付と成功/失敗で記録します。`--summary-only` を付けるとDry Runの一覧を省略して件数だけ表示します。

## 計算対象外への変更

指定期間内の指定口座にある、マイナス金額の振替以外の明細をDry Runで確認します。`--from` と `--to` は両端を含み、`--from` 省略時は利用可能な全期間、`--to` 省略時は今日までです。口座名は空白を正規化した完全一致で判定し、すでに計算対象外の明細はスキップします。`--account` は必須です。

```bash
npm run dry-run:exclude -- --account="理セゾンカード" --from=2026-05-01 --to=2026-05-31
```

一覧を確認した後、同じ条件で計算対象外に変更する場合:

```bash
npm run apply:exclude -- --account="理セゾンカード" --from=2026-05-01 --to=2026-05-31
```

Apply時も全月を再走査し、各明細の直前に日付・内容・金額・口座・計算対象状態を再確認します。画面スイッチで更新し、対象フラグと表示状態の両方でOFFを確認します。1件でも失敗した場合は残りを停止します。`--summary-only` を付けるとDry Runの一覧を省略して件数だけ表示します。
