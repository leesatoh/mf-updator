# mf-updator

Money Forward MEをローカルのPlaywrightブラウザーから操作するためのツールです。

## セットアップとログイン

```bash
npm install
npx playwright install chromium
npm run login
```

ブラウザーが開いたらMoney Forward MEに手動でログインしてください。口座ページへの到達を確認すると、認証状態を `data/auth-state.json` に保存します。次回の `npm run login` では保存済み状態を読み込み、期限切れの場合はブラウザー上で再ログインできます。

認証状態はローカルの`data/auth-state.json`に保存され、Git管理対象外です。CSVなどの家計データも`data/`以下に保存されます。`.env`はこのプロジェクトでは使用しません。パスワードや二段階認証の自動入力は行いません。

## 日付範囲

日付範囲を受け付けるコマンドでは、`--from`と`--to`は両端を含みます。`--to`を省略すると今日までが対象です。振替解除・計算対象変更は`--from`省略時に利用可能な最古月まで走査します。振替訂正候補は`--from`が必須です。分類設定とCSV取得は`--from`と`--to`の両方が必須です。

明細が表示されない場合は、対象日が指定期間内か確認してください。期間外の明細は候補に含まれません。意図しない広範囲の走査を避けるため、通常は`--from`と`--to`を明示してください。CSV取得は日単位ではなく、指定した開始月から終了月までの各月全体が対象です。

## 明細の確認

```bash
npm run inspect
```

保存済み認証状態で家計簿ページを開き、表示中の先頭1件を読み取り専用で表示します。明細がない場合や画面構造を確認できない場合は停止します。明細の変更は行いません。

振替候補を1件だけ確認する場合:

```bash
npm run inspect:transfer
```

大項目欄が空の明細を振替候補として扱います。候補がない場合は停止します。

## 振替解除

対象期間は指定した日付に基づきます。以下の口座名・内容は例なので、実際の明細に合わせて置き換えてください。

```bash
npm run dry-run -- --from=2026-05-01 --to=2026-05-31 --description="口座振替" --account="銀行口座/サブ口座"
```

`--from` と `--to` は両端を含みます。`--from` を省略すると利用可能な最古月まで、`--to` を省略すると今日まで走査します。一致した振替明細を一覧表示します。表示内容を確認した後、同じ条件を `apply` に渡すと、一件ずつ解除します。

```bash
npm run apply -- --from=2026-05-01 --to=2026-05-31 --description="口座振替" --account="銀行口座/サブ口座"
```

各明細の直前にID・内容・金額・振替状態を再確認します。確認UIが解除を示さない場合、解除後の画面状態を確認できない場合、または1件でも失敗した場合は残りを停止します。結果は明細の日付と成功/失敗で記録します。`--summary-only` を付けるとDry Runの一覧を省略して件数だけ表示します。

## 計算対象ON/OFF

指定期間内の指定口座にある、振替以外の明細の計算対象をON/OFFします。`--account` は必須です。`--target=on|off` は省略時 `off`、`--description` は省略時すべての内容、`--sign=plus|minus` は省略時 `minus` です。口座名は空白を正規化した完全一致で判定し、すでに指定状態の明細はスキップします。日付範囲は両端を含みます。

```bash
npm run dry-run:exclude -- --account="カード口座" --from=2026-05-01 --to=2026-05-31 --target=off --description="対象内容" --sign=minus
```

内容指定を省略すると口座内の全内容が対象になります。計算対象をONにする例:

```bash
npm run dry-run:exclude -- --account="カード口座" --from=2026-05-01 --to=2026-05-31 --target=on --sign=plus
```

Dry Runの一覧を確認してから、同じ条件を `apply:exclude` に渡すと一件ずつ変更します。各明細の直前に日付・内容・金額・口座・現在状態を再確認し、更新後に対象フラグと画面状態の両方を検証します。1件でも失敗した場合は残りを停止します。`--summary-only` を付けるとDry Runの一覧を省略して件数だけ表示します。

## 振替訂正候補の確認

指定した元口座の振替明細を、同日・絶対金額・相手口座が一致する通常明細と照合します。口座名に `親口座/口座名` を指定した場合、画面表示と照合するのは最後の口座名部分です。明細内容は相手候補の照合に使いません。一致が1件なら候補、0件または複数件ならそれぞれ表示してskipします。走査範囲を限定するため `--from` は必須です。

```bash
npm run dry-run:correct-transfer -- --from=2025-04-25 --to=2025-04-25 --description="口座振替" --account="元口座/サブ口座" --counter-account="相手口座/サブ口座"
```

Money Forwardの画面では相手の既存明細を直接選ぶ手段を確認できていないため、この機能は候補表示のみです。レコードの変更やApplyは行いません。`--summary-only` を付けると候補の詳細を省略して件数だけ表示します。

## 月別CSVの取得

指定期間に含まれる全月について、Money Forwardの月次CSVを `data/csv-downloads/YYYY-MM.csv` に保存します。期間の開始月・終了月も月全体のCSVになります。取得には `--from` と `--to` の両方が必要です。

```bash
npm run download:csv -- --from=2026-05-01 --to=2026-10-12
```

`--from`と`--to`は両方必須です。期間を指定しない場合はエラーになり、CSVは取得されません。`--combine`を付けると、今回取得した月別CSVをヘッダー1行の`data/csv-downloads/combined.csv`に結合します。列構成が月ごとに異なる場合は結合を中止し、月別CSVはそのまま残します。

```bash
npm run download:csv -- --from=2026-05-01 --to=2026-10-12 --combine
```

## 大項目・中項目の設定

期間・内容・口座・金額がすべて一致する明細の分類を設定します。`--from`、`--to`、`--description`、`--account`、符号付きの`--amount`、`--large-category`、`--middle-category`は必須です。内容と口座は正規化後の完全一致、金額は符号を含む円単位の完全一致です。大項目・中項目名も完全一致で照合します。

```bash
npm run dry-run:set-category -- --from=2026-05-01 --to=2026-05-31 --description="内容" --account="口座名" --amount=-1234 --large-category="食費" --middle-category="食料品"
```

候補と現在の分類を確認してから、同じ条件でApplyします。一致する明細が複数ある場合はすべて対象です。中項目を選択すると、その親の大項目も同時に設定します。分類名の組み合わせが一意でない場合、走査が未完了の場合、または更新後の再読込で分類を確認できない場合は停止します。

```bash
npm run apply:set-category -- --from=2026-05-01 --to=2026-05-31 --description="内容" --account="口座名" --amount=-1234 --large-category="食費" --middle-category="食料品"
```
